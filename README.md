# LogAnalyzer

Небольшая консольная программа на Python для разбора лог-файла: считает записи по уровням, неудачные входы и IP-адреса, с которых эти входы были.

## Возможности

- Запрашивает у пользователя имя файла с логом
- Если файл не найден, выводит понятное сообщение и завершает работу без Traceback
- Подсчёт записей по уровням (INFO, WARNING, ERROR, DEBUG и любым другим, которые встретятся в логе)
- Подсчёт неудачных входов (события `login_failed`)
- Список IP-адресов с неудачными входами, от самых частых к редким
- Строки неправильного формата не ломают программу, они пропускаются и считаются отдельно

## Формат лога

Каждая строка: дата, время, уровень, событие и поля через пробел.

```
2026-11-04 10:15:09 WARNING login_failed user=root ip=198.51.100.7
2026-11-04 10:17:45 ERROR disk_full host=srv1
```

В `test.log` лежат выдуманные тестовые данные (IP из специальных тестовых диапазонов).

## Запуск

```
python3 main.py
```

Затем ввести имя файла с логом, например `test.log`.

## Пример вывода

```
Подсчет по записям: {'INFO': 4, 'WARNING': 6, 'ERROR': 2, 'DEBUG': 1}

IP с неудачными входами
198.51.100.7 - 4
203.0.113.9 - 1

Ошибочная строка: 2

Не удачные входы: 5
```

Если файла нет:

```
Файл не найден по причине [Errno 2] No such file or directory: 'nope.log'
```

## Требования

- Python 3.9 или новее
- Только стандартная библиотека

## Ограничения

- Ожидается именно такой формат строки: уровень третьим словом, событие четвёртым, IP у `login_failed` шестым
- Строки короче 5 слов считаются ошибочными
- Другие ошибки при открытии файла (например, нет прав на чтение) не обрабатываются
