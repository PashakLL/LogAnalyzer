# CheckSize

Небольшая консольная программа на Python: показывает самые большие файлы в выбранной папке, включая все вложенные подпапки. Удобно, когда нужно быстро понять, что занимает место.

## Возможности

- Просмотр папки вместе со всеми подпапками
- Топ-5 самых больших файлов, от большего к меньшему
- Полный путь к каждому файлу и размер в МБ
- Понятные сообщения, если папки не существует или в ней нет файлов

## Требования

- Python 3.9 или новее
- Только стандартная библиотека (`pathlib`), ничего устанавливать не нужно

## Запуск

```bash
python3 CheckSize.py
```

Программа попросит ввести путь к папке.

## Пример

```
Введите путь к папке: /home/user/testdir
1. /home/user/testdir/video/lesson.mp4 - 66.24 мб.
2. /home/user/testdir/lesson2.mp4 - 36.08 мб.
3. /home/user/testdir/screenshot.png - 1.75 мб.
4. /home/user/testdir/book.epub - 0.62 мб.
5. /home/user/testdir/archive.zip - 0.08 мб.
```

Если папки нет, выводится `Папка не найдена`. Если папка есть, но файлов в ней нет, выводится `Файлов в папке нет`.

## Ограничения

- Количество файлов в топе (5) задано в коде
- Скрытые файлы (например, `.DS_Store` на macOS) тоже учитываются
- Ошибки доступа к закрытым папкам (`PermissionError`) не обрабатываются
- Если сделать срез количества файлов в топе 0, то программа выдаст `Файлов в папке нет`, даже если они там есть
