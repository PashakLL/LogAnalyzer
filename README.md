# LogAnalyzer

Небольшая консольная программа на Python для разбора лог-файлов.

## Что умеет сейчас

- Читает лог-файл `test.log`
- Считает количество строк
- Разбивает строку лога на части

## Планы

- Подсчёт записей по уровням (INFO, WARNING, ERROR)
- Самые частые IP-адреса
- Подсчёт неудачных входов

## Формат лога

```
2026-11-04 10:15:01 INFO login_ok user=admin ip=192.0.2.10
```

В `test.log` лежат выдуманные тестовые данные (IP из специальных тестовых диапазонов).

## Запуск

```
python3 main.py
```

## Требования

- Python 3.9 или новее
- Только стандартная библиотека
